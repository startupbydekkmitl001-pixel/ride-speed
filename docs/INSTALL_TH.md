# วิธีติดตั้ง Ride Speed V5 บน iPhone และ Android

**คู่มือสำหรับซอร์ส V5 — อัปเดต 1 ตุลาคม 2026** แอปเปิดที่แผนที่ในตัว รองรับไทย/อังกฤษ บันทึกทริปลงเครื่อง และใช้บัญชีออนไลน์สำหรับข้อมูลส่วนตัวกับการแชร์ ระบบ Google และการอ่านโปรไฟล์/หน้าคอมมูนิตี้ว่างผ่านการทดสอบในเว็บแล้ว ส่วนการติดตั้ง GPS รูปภาพ การอัปเดตทับและความลื่นบน iPhone 14 Plus/Android ยังต้องทดสอบกับเครื่องจริง ชื่อเมนูอาจต่างกันตามภาษาและเวอร์ชัน

## ไฟล์ V5 ที่ตรวจแพ็กเกจแล้ว — รุ่นทดลองจาก 7bb3665

บิลด์ iPhone และ Android สำเร็จ และตรวจไฟล์ที่ดาวน์โหลดจริงแล้วว่า commit, SHA-256, โค้ดแอป, MapLibre/Skia และวิดีโอ 28 ชุดพร้อมโปสเตอร์ตรงกับซอร์สที่ระบุ ยังต้องติดตั้งและทดสอบกับเครื่องจริง ชุดนี้เป็นรุ่นทดลอง ไม่ใช่รุ่นเผยแพร่ผ่านร้านค้า การแก้หน้าเว็บและซอร์สงาน cleanup ภายหลังไม่อยู่ในแพ็กเกจ 7bb3665 นี้

**บิลด์ 9 เป็นรุ่นย้อนหลัง:** รุ่น **0.1.0 (9.1.0)** จาก `df1e7db` มี [Release เก่า](https://github.com/startupbydekkmitl001-pixel/ride-speed/releases/tag/preview-0.1.0-build9) และ [บิลด์ #9](https://github.com/startupbydekkmitl001-pixel/ride-speed/actions/runs/36750133009) ที่ตรวจแพ็กเกจแล้ว แต่ใช้ Apple Maps และข้อจำกัดรุ่นเดิม ไม่รวม V5 MapLibre, journal ถาวร และ Ranked/Community/motion ชุดปัจจุบัน เก็บลิงก์นี้เพื่ออ้างอิงประวัติเท่านั้น

ใช้ iPhone ที่เป็น **iOS 17 ขึ้นไป**, คอมพิวเตอร์ Windows, สาย USB, อินเทอร์เน็ต และ Apple Account ของตัวเอง ไม่ต้องสมัคร Apple Developer แบบเสียเงิน

## 1. เตรียมคอมพิวเตอร์

1. เปิด [เว็บไซต์ Sideloadly ทางการ](https://sideloadly.io/) แล้วดาวน์โหลดรุ่น Windows ที่ตรงกับเครื่อง
2. จากหน้าเดียวกัน ดาวน์โหลด **Web iTunes** และ **Web iCloud** ตามลิงก์ของผู้พัฒนา Sideloadly ระบุให้ใช้รุ่นที่ดาวน์โหลดจากเว็บ ไม่ใช่รุ่น Microsoft Store หากมีรุ่น Store ให้เปลี่ยนตามคำแนะนำหน้านั้นก่อน
3. ติดตั้งโปรแกรม แล้วเปิด Sideloadly บนคอมพิวเตอร์
4. จากลิงก์ชุด V5 ในตารางด้านบน ดาวน์โหลด **Release unsigned IPA** พร้อมไฟล์ `.json` และ `.sha256` ของชุดเดียวกันจากส่วน **Assets** ไม่ต้องแตกไฟล์ IPA และห้ามใช้ `Source code.zip` แทน

ถ้าใช้ artifact จาก Actions ให้เลือก **`ios-release-…` ของบิลด์ V5 ที่ระบุ** แล้วแตก ZIP ชั้นนอกเพียงครั้งเดียวเพื่อเอาไฟล์ IPA ไฟล์จาก Actions มีวันหมดอายุและอาจต้องเข้าสู่ระบบ GitHub ใช้เลข run/commit ที่แจกคู่กับไฟล์ แทนการเลือกบิลด์เก่าจากชื่อแอปเพียงอย่างเดียว

การดาวน์โหลดสำเร็จยังไม่ใช่ผลทดสอบการติดตั้ง ใช้รุ่น `release` สำหรับเปิดโดยไม่ต้องต่อ Metro; รุ่น `development` ใช้ตรวจแก้แอปเท่านั้น ไฟล์ที่ลงท้าย `unsigned.ipa` ต้องเซ็นผ่าน Sideloadly ก่อนติดตั้ง ไม่สามารถแตะติดตั้งจาก Safari ได้โดยตรง

## 2. ติดตั้งแอปครั้งแรก

1. ต่อ iPhone กับคอมพิวเตอร์ด้วยสาย ปลดล็อกหน้าจอ แล้วแตะ **เชื่อถือ / Trust** เมื่อเครื่องถามเรื่องคอมพิวเตอร์นี้
2. เปิด Sideloadly เลือก iPhone ของตัวเอง แล้วลากไฟล์ `.ipa` ลงไป
3. ใส่ Apple Account ของตัวเอง เปิดตัวเลือก **Automatic Refresh** แล้วกด **Start**
4. ใส่รหัสผ่านและรหัสยืนยันของ Apple ในหน้าต่างที่โปรแกรมร้องขอ ไม่ต้องส่งข้อมูลเหล่านี้ให้ผู้ดูแลแอป
5. รอให้ติดตั้งเสร็จและเห็นไอคอนแอป เก็บสายต่อไว้หากยังมีขั้นตอนค้างอยู่

ขั้นตอนติดตั้งอ้างอิง [Sideloadly](https://sideloadly.io/) ใช้โหมดลงแอปด้วย Apple ID และค่าเริ่มต้น ไม่ต้องเพิ่มส่วนเสริมหรือเปลี่ยน Bundle ID

## 3. เปิด Developer Mode และเชื่อถือผู้พัฒนา

1. ลองเปิดแอปหนึ่งครั้ง หากมีข้อความให้เปิด Developer Mode ให้กดตกลง
2. ไปที่ **การตั้งค่า → ความเป็นส่วนตัวและความปลอดภัย → โหมดนักพัฒนา** (`Settings → Privacy & Security → Developer Mode`)
3. เปิดสวิตช์ แล้วกดรีสตาร์ท หลังเครื่องเปิดใหม่ ปลดล็อกและยืนยัน **Turn On** พร้อมรหัสปลดล็อกเครื่อง
4. หากยังขึ้น `Untrusted Developer` ให้ไปที่ **Settings → General → VPN & Device Management** เลือกบัญชีที่ใช้ลงแอป แล้วกด **Trust**
5. กลับมาเปิดแอปอีกครั้ง หากยังไม่เห็น Developer Mode ให้ตรวจว่าลงแอปเสร็จแล้วและลองเปิดไอคอนก่อน

การเปิดโหมดและรีสตาร์ทอ้างอิง [Apple](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device) และ [วิธีเปิดบน iPhone โดยไม่ใช้ Mac ของ Expo](https://docs.expo.dev/guides/ios-developer-mode/) ส่วนการเชื่อถือบัญชีอ้างอิง [Sideloadly FAQ](https://sideloadly.io/faq)

V5 อธิบายสิทธิ์ตำแหน่งตอนเริ่มใช้งานและเมื่อเลือกหาตำแหน่ง/เริ่มบันทึก เปิด **Precise Location** เพื่อให้คุณภาพตำแหน่งดีที่สุดตามที่เครื่องรองรับ แอปบันทึกเฉพาะขณะเปิดอยู่ และพักการเก็บตำแหน่งเมื่อเข้าเบื้องหลังหรือล็อกจอ ยังไม่มีการบันทึกต่อเนื่องขณะล็อกจอหรือ Motion & Fitness

## หลังเปิดแอปครั้งแรก

1. เข้าสู่ระบบด้วย Google แล้วทำขั้นตอนภาษา สิทธิ์ตำแหน่งและโปรไฟล์ตามหน้าจอ ขั้นตอนที่มีปุ่มข้ามทำภายหลังได้ ผู้ใช้ใหม่ตั้งชื่อของตัวเอง; เจ้าของโครงการใช้ Google บัญชีเดิมเพื่อเปิด Arnalxz / @arnalxz การสมัครอีเมลสำหรับคนทั่วไปยังขึ้นกับการตั้งค่าผู้ส่งอีเมลของโครงการ
2. หลังเข้าสู่ระบบ หน้าหลักเป็นแผนที่ **MapLibre + OpenFreeMap ในแอป** ใช้ปุ่มหาตำแหน่งหรือเริ่มทริปเมื่อพร้อม เลือกไทย/อังกฤษ หน่วยและธีมได้ในการตั้งค่า
3. ใน **โรงรถ** กดบวก เลือกสกู๊ตเตอร์ บิ๊กไบค์หรือรถยนต์ แล้วค้นหารุ่น/ตัวเลือก มีทางเพิ่มรุ่นเองเมื่อไม่พบรถของคุณ รถน้ำมันใช้ซีซี ส่วนรถไฟฟ้าใช้กำลังมอเตอร์ kW เลือกรถที่ใช้งานก่อนเริ่มทริป
4. รูปโปรไฟล์และรูปรถเป็นตัวเลือก ไม่ต้องอัปโหลดเพื่อเริ่มใช้ รูปโปรไฟล์เปิดตามสิทธิ์ของเจ้าของหรือเพื่อนที่ยอมรับแล้วและไม่ได้บล็อกกัน ส่วนรูปรถเปิดให้เจ้าของบัญชีเท่านั้น รูปเก็บในพื้นที่ส่วนตัว ไม่ใช่ลิงก์สาธารณะโดยอัตโนมัติ ร่างรูปและการเปลี่ยนแปลงที่ยังส่งไม่สำเร็จเก็บในเครื่องเพื่อทำต่อได้
5. เปิดการวางเส้นทางจากแผนที่ เพิ่ม/ย้ายจุด แล้วกดคำนวณถนนเมื่อยินยอมส่งจุดให้ผู้ให้บริการ **Geoapify ผ่านเซิร์ฟเวอร์** บันทึกชื่อและผู้ชมที่เลือก เส้นทางถนนกับแนวทริปที่บันทึกจริงแยกกัน; จุดที่ยังไม่ได้คำนวณไม่แสดงเป็นถนนที่ยืนยันแล้ว การค้นหา/คำนวณใหม่ใช้เน็ต และยังไม่มีแผนที่ออฟไลน์หรือระบบนำทางเลี้ยวต่อเลี้ยว
6. เริ่ม/พัก/หยุดทริปจาก HUD ข้อมูลต้นฉบับกับ checkpoint บันทึกลง **SQLite บน iPhone/Android** แยกตามบัญชี จบทริปแล้วสรุปส่วนตัวจะรอซิงก์เมื่อออนไลน์ เปิดแอปใหม่ยังอ่านประวัติและสถานะที่บันทึกไว้ได้; ถ้าการเก็บตำแหน่งถูกขัดจังหวะ แอปแสดงช่วงขาด ไม่สร้าง GPS ย้อนหลัง สรุปทริปทั่วไปไม่ใช่หลักฐานที่ผ่านการตรวจสำหรับอันดับ
7. เพิ่มเพื่อนด้วยชื่อผู้ใช้ ลิงก์หรือ QR แล้วให้เพื่อนยอมรับ สถานะและการแชร์ตำแหน่งต้องเลือกแยกกัน คอมมูนิตี้แนบสรุปทริป/เส้นทาง รูปได้สูงสุดหกรูป และข้อความได้ตามหน้าจอ ตรวจผู้ชมก่อนเผยแพร่; การแชร์ไม่เปิดตำแหน่งสดให้อัตโนมัติ
8. **อันดับ** ใช้เฉพาะผลที่เข้าเงื่อนไข ตรวจด้วยวิธีที่ระบุ และเจ้าของเลือกแชร์ ไม่ใช้ความเร็วที่กรอกในโพสต์หรือยอดสูงสุดจากทริปทั่วไป หน้าว่างเมื่อไม่มีผลจริง ส่วน convoy/การแข่งขันสดยังปิดจนกว่าจะผ่านการตั้งค่าระบบและการทดสอบสองเครื่องในสนามที่ผู้ดูแลอนุมัติ

ก่อนทดสอบ ให้จอดและจัดวางโทรศัพท์ให้เรียบร้อย ลองเริ่ม/พัก/หยุด เปิดแอปใหม่และตรวจประวัติก่อนบันทึกทริปจริง การบันทึกในเครื่องของ V5 ไม่ใช่หน่วยความจำชั่วคราวแบบบิลด์ 9 แต่การลบแอป/ข้อมูลแอปหรือบัญชีอาจลบข้อมูลเฉพาะเครื่องได้ การซิงก์สรุปส่วนตัวไม่ใช่การสำรอง GPS ดิบทั้งหมด และยังไม่ยืนยันระบบส่งออก/กู้คืนทริปทั้งชุด ดู [แผนทดสอบ V5](TEST_PLAN.md#current-v5-native-acceptance)

## 4. ต่ออายุแอปก่อนครบ 7 วัน

Sideloadly ระบุว่าบัญชีฟรีลงแอปทดลองได้สูงสุด **3 แอปต่อเครื่อง** และใบอนุญาตแอปมีอายุ **7 วัน** การต่ออายุคือการเซ็นแอปเดิมใหม่ ไม่ใช่การสมัครสมาชิก หากลงรุ่นนักพัฒนาเพิ่มอีกตัว จะใช้เพิ่มอีกหนึ่งช่อง [ข้อจำกัดและการรีเฟรชจาก Sideloadly FAQ](https://sideloadly.io/faq) ส่วน Apple อธิบายว่า Personal Team ต้องทำ provisioning ใหม่เป็นระยะใน [เอกสารบัญชีผู้พัฒนา](https://developer.apple.com/help/account/basics/about-your-developer-account)

วิธีง่าย: ขณะไม่ได้บันทึกทริป ต่อสาย USB แล้วใช้ **Refresh All Apps Manually** ในเมนู Sideloadly หรือเปิด IPA เดิมแล้วลงทับด้วยบัญชีเดิม ทำก่อนออกทริปยาว [การรีเฟรชแบบใช้สาย](https://sideloadly.io/changelog.html)

ตั้งรีเฟรชผ่าน Wi-Fi:

1. ต่อสาย เปิด iTunes แล้วเลือกไอคอน iPhone
2. เปิด **Summary** ติ๊ก **Sync with this iPhone over Wi-Fi** แล้วกด **Apply**
3. ให้ iPhone และคอมพิวเตอร์อยู่เครือข่ายเดียวกัน เปิดคอมพิวเตอร์และให้ Sideloadly Daemon ทำงาน
4. ตรวจใน Sideloadly ว่าแอปเข้าร่วม Automatic Refresh แล้ว หากต่อแบบไร้สายไม่สำเร็จ ให้ใช้สาย USB

การตั้ง Wi-Fi อ้างอิง [Apple iTunes สำหรับ Windows](https://support.apple.com/en-gb/guide/itunes/itns3751d862/windows) และการรีเฟรชอ้างอิง [Sideloadly changelog](https://sideloadly.io/changelog.html) ปิดคอมพิวเตอร์อยู่จะรีเฟรชไม่ได้ หลังรีเฟรชให้ลองเปิดแอปก่อนออกเดินทาง

## 5. อัปเดตรุ่นใหม่โดยเก็บทริปเดิม

1. จบทริปและหยุดบันทึกก่อน
2. ตรวจประวัติในเครื่อง สถานะซิงก์และร่างที่ยังส่งไม่สำเร็จ ถ้ารุ่นที่ใช้อยู่มีปุ่มส่งออก ให้เก็บสำเนาไว้นอกแอปและตรวจว่าเปิดได้ คู่มือนี้ไม่ยืนยันว่ามีการสำรอง/กู้คืน GPS ดิบทั้งหมด; อย่าตีความข้อความ “ซิงก์แล้ว” ว่าได้สำรองทุกไฟล์
3. ดาวน์โหลด IPA รุ่นใหม่ แล้วลง **ทับแอปเดิม** ผ่าน Sideloadly ใช้ **Apple Account เดิมและ Bundle ID เดิม** หากเคยตั้ง ID เองต้องใช้ค่าเดิม เปิด Automatic Refresh ไว้
4. **อย่าลบแอปเก่าก่อนอัปเดต** เปิดรุ่นใหม่แล้วตรวจว่าทริปและการตั้งค่าเดิมยังอยู่

เงื่อนไขลงทับอ้างอิง [Sideloadly FAQ](https://sideloadly.io/faq) ส่วนการสำรองและตรวจข้อมูลเป็นแนวทางของโครงการ เราจะทดสอบการเก็บข้อมูลหลังอัปเดตก่อนแจกให้เพื่อน

ถ้าครบ 7 วันแล้วเปิดไม่ได้ ให้ลองรีเฟรชหรือลง IPA ทับด้วยบัญชีและ ID เดิมก่อน อย่ารีบลบแอป การลบแล้วลงใหม่เสี่ยงเสียข้อมูล และคู่มือนี้ยังไม่ยืนยันว่ามีปุ่มกู้คืนข้อมูลในแอปปัจจุบัน

## 6. ถ้าติดปัญหา

| อาการ | ทำอย่างไร |
|---|---|
| ไม่เห็น iPhone | ปลดล็อก ตรวจว่าเชื่อถือคอมพิวเตอร์แล้ว ลองสาย/พอร์ตอื่น และดูว่า iTunes เห็นเครื่องหรือไม่ |
| `Untrusted Developer` | ทำขั้นตอนเชื่อถือบัญชีในข้อ 3 |
| `Developer Mode Required` | เปิดโหมด รีสตาร์ท แล้วกดยืนยันหลังเครื่องเปิดใหม่ |
| ครบ 3 แอปหรือ App IDs เต็ม | ส่งข้อความผิดพลาดให้ผู้ดูแลตรวจ อย่าเปลี่ยน ID ไปเรื่อย ๆ เพราะจะสร้าง ID เพิ่ม |
| เปิดได้แต่ไม่มีความเร็ว | ตรวจสิทธิ์ตำแหน่ง แล้วลองในที่โล่ง ค่าที่อ่านไม่ได้ควรแสดง `—` |
| มีข้อผิดพลาดอื่น | ส่งข้อความผิดพลาดพร้อมรุ่น iPhone, iOS, Sideloadly และรุ่นแอป ปิดบังอีเมล/รหัส/ข้อมูลบัญชีก่อนส่ง |

ข้อจำกัดและแนวทางปัญหาติดตั้งดู [Sideloadly FAQ](https://sideloadly.io/faq) หากเวอร์ชันโปรแกรมไม่ตรงกับคู่มือ ให้ผู้ดูแลทดสอบชุดเวอร์ชันนั้นก่อน ไม่ต้องดาวน์โหลดตัวแก้จากเว็บอื่น

ถ้าบิลด์ที่ติดตั้งมีปุ่มส่งออกรายงาน ให้จบทริปแล้วตรวจว่ามีตำแหน่งที่ไม่ต้องการแชร์หรือไม่ก่อนส่งให้ผู้ดูแล การส่งออก/สำรองทั้งชุดยังเป็นงานที่ต้องยืนยันแยกจาก journal ถาวรในเครื่อง

## Android preview APK

ชุด Android เป็น **standalone preview** ที่ฝัง JavaScript ไว้ เปิดได้โดยไม่ต้องต่อ Metro ใช้ใบรับรอง debug สาธารณะของ CI เพื่อทดสอบเท่านั้น ไม่ใช่ใบรับรองสำหรับเผยแพร่ผ่านร้านค้า และยังไม่มีผลยืนยันการติดตั้ง/GPS/FPS บนเครื่องจริง

1. ดาวน์โหลด `.apk`, `.json` และ `.sha256` ของชุด V5 ที่ระบุในตารางด้านบน หากดาวน์โหลด artifact `android-preview-debug-signed-…` จาก Actions ให้แตก ZIP ชั้นนอกเพื่อเอา APK ตรวจ SHA-256 เช่นเดียวกับ IPA
2. เปิด APK บน Android แล้วทำตามหน้าจอติดตั้ง หากระบบขอสิทธิ์ติดตั้งจากแอปที่ใช้เปิดไฟล์ ให้อนุญาตสำหรับแอปนั้นตามเมนูของเครื่อง ชื่อเมนูและขั้นตอนอาจต่างกันตามยี่ห้อ/เวอร์ชัน ดู [คำอธิบายการติดตั้งจากแหล่งอื่นของ Google](https://support.google.com/android/answer/9457058?hl=en)
3. เปิดแอปโดยปิด Metro/ถอดสาย ใช้บัญชี Google ของตัวเอง แล้วทดสอบขั้นตอนแรกและการบันทึกขณะเปิดแอปตามรายการด้านบน บันทึกรุ่นโทรศัพท์ Android และเลขบิลด์จริงก่อนรายงานผล
4. อัปเดตด้วย APK ชุดใหม่ที่ package ID และใบรับรองตรงกับตัวเดิม หากขึ้นลายเซ็นไม่ตรงหรือรุ่นเก่ากว่า ให้ส่งข้อความให้ผู้ดูแลตรวจ metadata แทนการลบแอปเพื่อแก้ เพราะการลบอาจเสียข้อมูลเฉพาะเครื่อง

หากเครื่องแสดงขั้นตอนยืนยันผู้พัฒนาเพิ่มเติม ให้เก็บข้อความเพื่อให้ผู้ดูแลเลือกวิธีทดสอบที่ตรงกับเครื่อง ข้อกำหนดและแหล่งติดตั้งในแต่ละประเทศกำลังทยอยเปลี่ยน คู่มือนี้ไม่ยืนยันว่า APK ติดตั้งได้ทุกเครื่อง ดู [Android developer verification จาก Google](https://support.google.com/android/answer/17065026?hl=en)

## สำหรับผู้ช่วยทดสอบรุ่นนักพัฒนาเท่านั้น

IPA รุ่นปกติที่แจกเพื่อนควรเปิดได้โดยไม่ต้องต่อคอมพิวเตอร์ ส่วนรุ่น Dev ต้องเชื่อม Metro บน Windows ตามคำแนะนำผู้ดูแล ทั้งสองรุ่นยังต้องต่ออายุใบอนุญาต 7 วันเหมือนกัน การสแกน QR ของ Metro ไม่ได้ต่ออายุใบอนุญาต [วิธีใช้ development build](https://docs.expo.dev/develop/development-builds/use-development-builds/)
